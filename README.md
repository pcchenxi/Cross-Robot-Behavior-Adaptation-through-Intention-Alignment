# Cross-Robot Behavior Adaptation through Intention Alignment

This repository contains code and related artifacts for the paper **[Cross-Robot Behavior Adaptation through Intention Alignment](https://doi.org/10.1126/scirobotics.adv2250)**, published in *Science Robotics*.

## Repository Structure

This repository is organized into two complementary parts:

- `experimental_analysis/` contains the paper artifacts, precomputed results, and analysis scripts used to generate the reported tables.
- `sim-picking-task/` contains the standalone simulated picking task code used for data collection, training, and online evaluation.

## Notes

The code for the item selection task has been refactored and improved since the paper was written. It should produces better results than those reported in the paper. Some hyperparameters have also been updated relative to the settings described in the paper.

The Author Accepted Manuscript (AAM) version of the paper is available in this repository:

[IAIL-aam.pdf](<./IAIL-aam.pdf>)
